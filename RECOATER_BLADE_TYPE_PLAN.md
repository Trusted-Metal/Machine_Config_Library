# Recoater Blade Type — Implementation Plan

**Status: done and verified, all five languages, 2026-09-11.** (All 9 steps complete. Working
tree has uncommitted changes — schema, all five languages' source/tests, regenerated fixtures,
and this documentation — deliberately left uncommitted; committing is being handled separately,
not by the agent that did this implementation work.)

**Scope:** add one new optional attribute to `Machine`:

| Field → on-disk attribute |
|---|
| `recoater_blade_type` → `Recoater_Blade_Type` |

Driven by `docs/clearbox-tauri-integration.md`'s field-mapping gap — `SettingsConfig::recoater_blade_type`
currently has no library counterpart and clearbox-tauri keeps a hardcoded default (`"Standard"`).

**Shape:** nullable string, identical contract to the two existing `Machine` fields
`gas_flow_direction` → `Gas_Flow_Direction` and `recoat_direction` → `Recoat_Direction`:

- Model/API layer: `Optional[str]` / `Option<String>` / `string | null` / `std::optional<std::string>` / `*string` — never required, no default value semantics beyond "absent = `None`/`null`".
- Read: attribute present and non-empty → the string; attribute absent or empty → `None`/`null`. No special-casing.
- Write: attribute always written; `None`/`null` serializes as an empty string (same as `Recoat_Direction`), never omitted.
- **No `File_Version` bump** — pure additive optional field on an existing group, in both v1.0 and v1.1, per `docs/contributing.md`: *"New optional field — add `field: Optional[T] = None`... All existing adapters automatically return `None` for it. ✅ Safe."*
- This is a **new orthogonal concept** (per `docs/contributing.md`'s "New field vs. replacement field" test) — nothing in the current model claims to hold recoater blade type in a different shape, so this is the simple additive case, not a v1.0→v1.1 transform.

This is simpler than `SCANNER_INVERT_FLAGS_PLAN.md`'s fields: no false/absent asymmetry, no
special serialization helper needed anywhere — the existing nullable-string read/write helpers
in every language already do exactly the right thing.
