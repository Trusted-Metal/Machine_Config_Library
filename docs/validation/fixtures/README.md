# Validation Fixtures

These files are hand-crafted HDF5 fixtures used by all five language validation
apps to test the adapter and versioning dispatch layer (AV-01 through AV-07).

Generated by `generate_fixtures.py` from `fixtures/reference_config.h5`.
Do not edit manually — regenerate with the script if the source fixture changes.

```
python docs/validation/fixtures/generate_fixtures.py \
    --source fixtures/reference_config.h5 \
    --outdir docs/validation/fixtures/
```

## Fixtures

| File | Scenario | Transformation |
|---|---|---|
| `v2_0_unknown.h5` | AV-01 | `File_Version` attr overwritten to `"2.0"` |
| `missing_version.h5` | AV-02 | `File_Version` attr deleted entirely |
| `v1_1_simulated.h5` | AV-03 | `File_Version` → `"1.1"`, `Future_Group/` subgroup added |
| `missing_machine_group.h5` | AV-04 | `Machine/` group deleted |
| `corrupt_scalar.h5` | AV-05 | `Machine/Build_Plate_X_Dimension` attr overwritten with string `"not_a_number"` |
| `version_whitespace.h5` | AV-06 | `File_Version` → `" 1.0 "` (leading and trailing space) |
| `empty_version.h5` | AV-07 | `File_Version` → `""` (empty string) |

## What each scenario tests

**AV-01** — The reader must raise a typed `UnsupportedFileVersion` error for an
unrecognised version string. Silent fallback to v1.0 would be the most dangerous
possible versioning failure.

**AV-02** — Files from pre-versioning tools lack the `File_Version` attribute.
The reader must handle this predictably (default to `"1.0"` or raise a typed
error) and behave identically across all five languages.

**AV-03** — A v1.0 reader must reject a v1.1 file loudly. Silently truncating
a future-version file to the v1.0 schema would corrupt data.

**AV-04** — Corrupt or hand-edited field files may be missing required HDF5
groups. The reader must raise a typed error rather than panicking or returning
a partially-populated model.

**AV-05** — Files written by non-library tools may have wrong attribute types.
`_read_float` must raise `ValueError` rather than silently returning `None` or
a garbage value.

**AV-06** — Real files from legacy tools have been observed with whitespace in
version strings. The dispatcher must strip and normalise before lookup.

**AV-07** — Establishes the empty-string contract explicitly. Must behave the
same as AV-02 (default to `"1.0"`) or raise a typed error — the same choice
must hold across all five languages.
